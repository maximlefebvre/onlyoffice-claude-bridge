Test the connection to Claude

The Claude Bridge plugin talks to a small server running on your computer (127.0.0.1). This page checks that the server is running and that your browser lets this site reach it.

1. Make sure Claude is running

Start a Claude Code session with the onlyoffice-bridge plugin installed (or any client that runs the MCP server). The server starts with the session.

2. Test the connection

Click the button. If your browser asks whether this site may access apps and services on this device, tick Remember this decision and choose Allow.

3. Go back to your document

Open (or reopen) the Claude Bridge panel in OnlyOffice. It connects by itself within a few seconds.

Firefox 151+: a permission given here applies to this page only. Inside the editor, the plugin runs in a frame where Firefox neither asks nor applies it, so the panel still needs the workaround described in the browser notes.
