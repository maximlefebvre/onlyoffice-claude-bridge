OnlyOffice Claude Bridge

Un plugin OnlyOffice qui permet à Claude d'éditer le document ouvert, via un serveur local sur ton ordinateur.

Adresse du store à coller dans OnlyOffice

https://maximlefebvre.github.io/onlyoffice-claude-bridge/store/index.html

Installer le plugin

  1. Ouvre un document dans ton éditeur OnlyOffice (par exemple dans kDrive).
  2. Va dans Plugins → Gestionnaire de plugins, puis clique sur </> (mode développeur).
  3. Colle l'adresse du store ci-dessus et valide.
  4. Installe Claude Bridge, ouvre son panneau, colle le jeton affiché par le serveur local, puis clique sur Connecter.
