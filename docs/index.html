OnlyOffice Claude Bridge

Let Claude read and edit the documents, spreadsheets and presentations you have open in OnlyOffice (kDrive, Nextcloud, DocSpace…), live, with your Claude subscription. No API key.

How it works

A Claude Code plugin runs a small server on your computer. A plugin inside the OnlyOffice editor connects to it from your browser. Claude then uses about fifty tools: text and formatting, styles, tables, comments, track changes, images, charts, slides, and the full OnlyOffice API for everything else.

Nothing goes through a third-party server: the editor plugin only talks to 127.0.0.1, and each browser has to be approved on your computer first.

Get started

  1. Add the Claude Code plugin: claude plugin marketplace add maximlefebvre/onlyoffice-claude-bridge claude plugin install onlyoffice-bridge@onlyoffice-bridge
  2. In OnlyOffice, open Plugins → Plugin Manager → </>, add this store and install Claude Bridge: https://maximlefebvre.github.io/onlyoffice-claude-bridge/store/index.html
  3. Allow your browser to reach Claude, then approve the first connection.
