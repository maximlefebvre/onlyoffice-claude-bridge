OnlyOffice Claude Bridge

An OnlyOffice plugin that lets Claude edit the open document, through a local server on your computer.

Store URL to paste into OnlyOffice

https://maximlefebvre.github.io/onlyoffice-claude-bridge/store/index.html

Install the plugin

  1. Open a document in your OnlyOffice editor (for example in kDrive).
  2. Go to Plugins → Plugin Manager, then click </> (developer mode).
  3. Paste the store URL above and confirm.
  4. Install Claude Bridge, open its panel, paste the token printed by the local server, then click Connect.
